Projomia · AI Work Context & Memory

Your privacy in Projomia.

This policy describes Projomia for iPhone and the Android early-access release. A Mac companion is not yet available; where this policy mentions Mac, it describes how the Mac companion will behave once released. It matches each app’s current behavior. It is not a promise about a future cloud service.

Last updated 19 November 2026.

What stays on the device

Photographs, notes, drawings, documents, Planner, Journal, and Daily Log are stored in the app on that iPhone or Mac. Projomia does not operate a cloud account or a Projomia server in this release. There is no Projomia login.

On iPhone and Mac, optional sync sends records directly between a paired Mac and iPhone on the local network. That transfer does not go through Projomia. Original files are checked before records are saved. If both devices changed the same record while offline, Projomia resolves it automatically using a fixed rule so both devices keep the same result. A superseded copy can remain in a private sync archive on the device; ordinary sync does not ask you to pick a version.

Optional AI

On iPhone and Mac, AI is off until you connect your own OpenAI API key or sign in with ChatGPT, and until you start an AI request or enable an optional automatic AI folder rule. Capture, notes, documents, Planner, Journal, and Daily Log work without a connection. The Android release described below does not include this AI connection.

A send goes to OpenAI at api.openai.com using your credential. Starting the request is the authorization. In Projomia AI / project chat, pressing Send authorizes that question, including automatic retrieval of project context and needed photograph or drawing extracts during the same request. Some other AI actions still show a confirmation dialog before the first send. An optional folder import rule can also send matching imported sources after you enable its AI permission on that device. A request can include:

  • Your question, notes, project and room names, local text from photos, drawing extracts, and a bounded amount of saved project memory.
  • Photographs. “Suggest information” sends a resized JPEG with GPS and other embedded metadata removed. Note investigation can send either a resized preview or the exact stored photograph, depending on the toggle on that screen. Projomia AI can retrieve needed originals or labelled extracts for the authorized question. An exact original can still contain location metadata if the file has it.

Those requests set store: false. Projomia does not keep a copy of the request on a server of its own. This does not mean OpenAI retains nothing. OpenAI’s own retention, including safety logging, still applies. Read OpenAI’s privacy policy and API data controls for its handling of requests.

Replies are saved in your local library as unverified conversation. They do not change your project until you confirm a change.

ChatGPT sign-in and keys

If you sign in with ChatGPT, Projomia stores that account email in the iPhone or Mac Keychain and sends an identifier the app generates to OpenAI so the sign-in can be recognized. A later sign-in can send the email back to OpenAI as a hint. An API key, if you save one, is also kept in the Keychain and is sent only to OpenAI when you make a request.

Sign out removes the local ChatGPT session. If OpenAI does not confirm remote revocation, disconnect the app in ChatGPT settings as well. Removing the API key deletes it from the Keychain. On iPhone, deleting the app removes its app-local library; offloading the app keeps its data. Copies on a paired device, exports, Photos, and device backups are separate and are not erased by deleting this app. Removing the Mac application alone may leave its library on that Mac. Export or copy what you need before deleting data.

Retention, deletion, and consent

Project records and saved conversations remain in your local library until you delete them. Use the app’s deletion and Cleanup controls to manage local records. Review copies on paired devices, exported files, and device backups separately. Signing out or removing a credential does not delete your project library.

You can stop future AI sharing by not starting AI requests, turning off optional automatic AI folder rules, and disconnecting your OpenAI credential in Settings. Where a confirmation dialog still appears, canceling that dialog also stops that send. Data already sent to OpenAI is subject to OpenAI’s retention and deletion procedures; Projomia cannot erase it from OpenAI by deleting a local record. For OpenAI data requests, use OpenAI’s privacy portal. Projomia has no server-held project library for the publisher to retrieve or delete.

What Projomia does not do

Projomia does not show ads, does not track you across other companies’ apps, and does not use an advertising identifier. It does not use the microphone. It does not read your whole photo library. On iPhone, saving to Photos happens only when you choose it. Import uses the photo picker. Live location is not collected. On iPhone and Mac, precise location leaves the device only as metadata already inside a photograph you choose to send as an exact original. On Android, a photograph you choose to share can still contain the metadata already in that file.

Data shared for app functionality

Optional OpenAI use can share Email Address, Photos or Videos, Precise Location, Other User Content, and User ID, as described above. These may be linked to your OpenAI account. Projomia does not use them for tracking.

Android

Projomia for Android stores photographs, notes, drawings, documents, journal entries, daily log entries, work records, and project team details you enter in the app on that phone. There is no Projomia account and no Projomia server. This Android release does not include Projomia AI, ChatGPT sign-in, or an OpenAI connection. It does not show ads, does not track you across other apps, and does not use an advertising identifier.

The phone camera is used only when you take a photo into a project. Import uses the system picker. Projomia does not read your whole photo library. When you share a photo or export a package, you choose the destination in Android’s share sheet.

Settings can listen for Projomia on the local network and show a pairing code. In this Android release a connection does not exchange the project library. Windows sync is not included.

You can delete photos, notes, journal entries, and a project on the phone. A project that still has drawings or documents must have those removed first. Cleanup removes photo files that are no longer linked to a record. Deleting the app removes its on-phone library. Android backup, a shared file, or an exported package can keep a separate copy. Projomia does not receive those copies and has no server library to delete.

Contact

For Projomia support, privacy questions, or deletion requests, email support@projomia.com. The publisher cannot access your device-local project library. If you email support, your email provider and the support mailbox provider process the information you choose to include. Send only what is needed to explain your request, and never send passwords or API keys.
