Projomia · AI Work Context & Memory

Your privacy in Projomia.

This policy describes Projomia for iPhone and Mac as prepared for the first public release. It matches the app’s current behavior. It is not a promise about a future cloud service.

Last updated 8 November 2026.

What stays on the device

Photographs, notes, drawings, documents, Planner, Journal, and Daily Log are stored in the app on that iPhone or Mac. Projomia does not operate a cloud account or a Projomia server in this release. There is no Projomia login.

Optional sync sends records directly between a paired Mac and iPhone on the local network. That transfer does not go through Projomia. Original files are checked before records are saved. If both devices changed the same record, Projomia keeps the versions for you to choose.

Optional AI

AI is off until you connect your own OpenAI API key or sign in with ChatGPT, and until you send a request. Capture, notes, documents, Planner, Journal, and Daily Log work without a connection.

A send goes to OpenAI at api.openai.com using your credential. The screen asks before the send. Depending on what you confirm, the request can include:

  • Your question, notes, project and room names, local text from photos, drawing extracts, and a bounded amount of saved project memory.
  • Photographs. “Suggest information” sends a resized JPEG with GPS and other embedded metadata removed. Note investigation can send the exact stored photograph, which is the default on that screen, and an authorized inspection can do the same. An exact original can still contain location metadata if the file has it. The screen states which kind of image is being sent.

Those requests set store: false. Projomia does not keep a copy of the request on a server of its own. This does not mean OpenAI retains nothing. OpenAI’s own retention, including safety logging, still applies. Read OpenAI’s privacy policy and API data controls for its handling of requests.

Replies are saved in your local library as unverified conversation. They do not change your project until you confirm a change.

ChatGPT sign-in and keys

If you sign in with ChatGPT, Projomia stores that account email in the iPhone or Mac Keychain and sends an identifier the app generates to OpenAI so the sign-in can be recognized. A later sign-in can send the email back to OpenAI as a hint. An API key, if you save one, is also kept in the Keychain and is sent only to OpenAI when you make a request.

Sign out removes the local ChatGPT session. If OpenAI does not confirm remote revocation, disconnect the app in ChatGPT settings as well. Removing the API key deletes it from the Keychain. On iPhone, deleting the app removes its app-local library; offloading the app keeps its data. Copies on a paired device, exports, Photos, and device backups are separate and are not erased by deleting this app. Removing the Mac application alone may leave its library on that Mac. Export or copy what you need before deleting data.

Retention, deletion, and consent

Project records and saved conversations remain in your local library until you delete them. Use the app’s deletion and Cleanup controls to manage local records. Review copies on paired devices, exported files, and device backups separately. Signing out or removing a credential does not delete your project library.

You can stop future AI sharing by declining sends, stopping optional AI workflows, and disconnecting your OpenAI credential in Settings. Data already sent to OpenAI is subject to OpenAI’s retention and deletion procedures; Projomia cannot erase it from OpenAI by deleting a local record. For OpenAI data requests, use OpenAI’s privacy portal. Projomia has no server-held project library for the publisher to retrieve or delete.

What Projomia does not do

Projomia does not show ads, does not track you across other companies’ apps, and does not use an advertising identifier. It does not use the microphone. It does not read your whole photo library. Saving to Photos happens only when you choose it. Import uses the photo picker. Live location is not collected. Precise location leaves the device only as metadata already inside a photograph you choose to send as an exact original.

Data shared for app functionality

Optional OpenAI use can share Email Address, Photos or Videos, Precise Location, Other User Content, and User ID, as described above. These may be linked to your OpenAI account. Projomia does not use them for tracking.
