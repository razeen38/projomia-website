AI Work Context & Memory

Support for Projomia.

Give AI the context to understand your work and solve real problems.

Capture the work. Connect the knowledge. Build the context. Solve the problem.

Projomia keeps a project’s photographs, notes, drawings, documents, Planner, Journal, and Daily Log on your iPhone, or on Android in early access.

Platforms

  • iPhone. The iPhone app stores the library on the phone.
  • Mac. A Mac companion is not available yet.
  • Android. The Android app stores photographs, notes, drawings, documents, journal, daily log, and work records on the phone. It does not include Projomia AI. Listening on the local network does not yet exchange the library.

Get the app

Request early accessAndroid

  • iPhone. Download Projomia on the App Store. It is free.
  • Android. Projomia is in early access on Google Play. Email support@projomia.com to request access, and include the Google account email you use on Google Play.

Get started

  1. Create a project.
  2. Add rooms or folders, then capture or import photographs and files.
  3. Write notes, use Planner, Journal, and Daily Log as the work needs them.
  4. Your library stays on the device. There is no Projomia server and no sync service in this release.

Offline and AI

Capture, browsing, notes, documents, Planner, Journal, and Daily Log work without a network. On iPhone, AI is optional. Connect your own OpenAI API key or ChatGPT account, then start a request when you want AI help. In Projomia AI, Send authorizes that question. The app works if you never turn AI on. The Android app does not include Projomia AI.

If something does not work

  • Camera access: allow Camera for Projomia in the device settings. The app takes still photos into the project you choose. On Android you can also import a photo without using the camera.
  • Sync: both devices need the local network permission, the same pairing code, and the app open. iPhone may pause sync in the background and resume when you return.
  • A conflict: if both devices changed the same record offline, sync resolves it automatically so both keep the same result. It does not ask you to pick a version for ordinary conflicts.
  • AI: check the selected model and that the device is online. A failed or cancelled request does not erase the local original.
  • Storage: the library lives in the app. Copy or export it before deleting Projomia.

Finder shows the iPhone app as Projomia. The library folder inside it is still named RoomLog.

Contact support

Email support@projomia.com for support or privacy requests. Include your app version, device model, and a short description of the issue. Share only the project information needed to explain it. Never send passwords or API keys. The publisher cannot access your device-local library.
