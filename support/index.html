Projomia keeps a project’s photographs, notes, drawings, documents, Planner, Journal, and Daily Log on your iPhone and Mac.

Platforms

  • iPhone. The first public release is the iPhone app.
  • Mac. The Mac app is the companion for the same local library and for direct sync.

Get started

  1. Create a project.
  2. Add rooms or folders, then capture or import photographs and files.
  3. Write notes, use Planner, Journal, and Daily Log as the work needs them.
  4. Pair the Mac and iPhone in Settings if you want both devices to hold the library. Sync is direct and local. It does not use a Projomia server.

Offline and AI

Capture, browsing, notes, documents, Planner, Journal, and Daily Log work without a network. AI is optional. Connect your own OpenAI API key or ChatGPT account, then confirm each send. The app works if you never turn AI on.

If something does not work

  • Camera access: allow Camera for Projomia in iPhone Settings. The app takes still photos into the project you choose.
  • Sync: both devices need the local network permission, the same pairing code, and the app open. iPhone may pause sync in the background and resume when you return.
  • A conflict: Projomia keeps both versions. Choose one in the sync screen. It does not silently drop a conflicting original.
  • AI: check the selected model and that the device is online. A failed or cancelled request does not erase the local original.
  • Storage: the library lives in the app. Copy or export it before deleting Projomia.

Finder shows the iPhone app as Projomia. The library folder inside it is still named RoomLog.
